# Vanilla2Eagler-Plus
让原版 Java Edition 1.8 客户端通过本代理进入 EaglercraftX 服务器/共享世界。以及以 共享世界房间 为入口让 Eagler玩家 进入原版服务器，并且支持 Eagler1.20.6 的玩家

原作者：EiluDick / ZDarkZ
